# ゴルフ練習ノート（Windows 用）

練習場で撮ったスイング動画を入れると、1球ずつに分けて、姿勢の計測・苦手のチェック・AI 分析・ドリルまでできるアプリです。
動画や記録は**自分のパソコンの中だけ**に保存されます。

## 入れ方（最初の1回だけ・10分ほど）

1. **[ここを押してダウンロード](https://github.com/kosuke20127-droid/golf-practice-app/archive/refs/heads/main.zip)**（ZIP ファイルが落ちてきます）
2. ダウンロードした ZIP を右クリック →「**すべて展開**」→「展開」
3. 開いたフォルダの中の「**install**」（install.bat）をダブルクリック
   - 青い画面で「Windows によって PC が保護されました」と出たら、「**詳細情報**」→「**実行**」を押してください
   - 途中で「このアプリがデバイスに変更を加えることを許可しますか？」と出たら「**はい**」
4. 終わるとアプリが開きます。最初に身長などを入れる画面が出るので、案内どおりに進めてください
5. 次からは、デスクトップの「**ゴルフ練習ノート**」をダブルクリックするだけです

※ 黒い画面（アプリ本体）は、使っている間は閉じないでください。閉じるとアプリが止まります。

## 使い方のポイント

- **動画を送る**：動画タブの「動画を送る」から。何球も続けて撮った動画でも、インパクトの音とスイングの動きから1球ずつに分けます
- **撮り方**：スマホを打つ方向と平行に置き、真後ろ（または正面）から、全身が入るように撮ると計測が正確になります
- **AI 分析**：最初の画面か設定タブで、Google の Gemini API キー（無料）を入れると使えます。なくても計測・苦手・ドリルは使えます
- **スマホから使う**：設定タブの「スマホから使う」をオンにすると、同じ Wi-Fi のスマホから開けます（表示されたアドレスをスマホのブラウザで開く）
- **更新**：新しい版が出ると、画面の上に「新しい版があります」と出ます。「更新する」を押すだけで入れ替わります（記録はそのままです）

## うまく動かないとき

- 「winget が見つかりません」と出た：Microsoft Store で「アプリ インストーラー」を入れて（更新して）から、もう一度 install を実行
- アプリが開かない：デスクトップの「ゴルフ練習ノート」をダブルクリックして、黒い画面に出ている文を確認してください
- もう一度入れ直したい：install をもう一度実行してください（記録は消えません）

記録は `C:\Users\（あなたの名前）\GolfPracticeApp\data` に入っています。パソコンを買い替えるときは、このフォルダをコピーしてください。
