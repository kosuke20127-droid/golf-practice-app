# ゴルフ練習ノート（パソコン版）

パソコンで動かしておき、スマホからはブラウザで開いて使う版です。
長い動画もパソコンでそのまま処理でき、記録・画像・動画はすべてパソコンに保存されます。

## できること

- 練習（打球記録）・ドリル・分析は claude.ai 版と同じ
- **動画**: スマホから送る／パソコンの「取り込みフォルダ」から選ぶ
  → インパクト音から1球ずつ自動で見つけ、1球ごとに
  「切り出した動画」「16コマ」「クラブ軌道画像」を保存
- **体の動きの自動計測**（MediaPipe・無料・パソコン内で計算）: テンポ、頭の動き、前傾角度の変化、
  肩と腰の回転・捻転差（正面から撮影時）、リード腕の伸び、フィニッシュの体重を ◎○△ で表示。
  「分析」タブで数値の推移をグラフで見られる
- **AI 分析**: Google の Gemini API キーを設定すると使える（Flash モデルは無料枠あり）。
  1球ごとに100点満点で採点、クラブの自動推定も
- 過去のスイングとの比較

## 準備（最初の1回だけ・Windows）

1. コマンドプロンプトで Python と ffmpeg を入れる
   ```
   winget install Python.Python.3.12
   winget install Gyan.FFmpeg
   ```
2. GitHub の Code → Download ZIP でこのリポジトリをダウンロードし、展開した中の `pc` フォルダを好きな場所に置く
3. `pc\start.bat` をダブルクリック
   （初回は必要なライブラリを自動で入れるので少し時間がかかります）
4. ブラウザで `http://localhost:8765/` が開けば成功です。黒い画面は閉じずに置いておきます

## スマホから使う（Tailscale）

外出先（練習場）のスマホから、自分のパソコンに安全につなぐための設定です。
自分の端末以外からは見えません。

1. パソコンとスマホに Tailscale を入れ、同じアカウントでログインする
   - パソコン: https://tailscale.com/download
   - スマホ: App Store / Google Play で「Tailscale」
2. パソコンのコマンドプロンプトで次を実行（1回でOK。再起動後も続きます）
   ```
   tailscale serve --bg 8765
   ```
   初回は HTTPS を有効にするよう案内が出るので、表示された URL を開いて許可します
3. 表示された `https://パソコン名.xxxx.ts.net/` をスマホで開く
4. 共有メニューから「ホーム画面に追加」すると、アプリのように使えます

スマホで使うときは、スマホの Tailscale アプリがオンになっていることを確認してください。
パソコンはスリープしないように設定しておきます（設定 → システム → 電源 → スリープ:「なし」）。

## 設定

アプリの「設定」タブで変更できます。

- **Gemini API キー**: https://aistudio.google.com/apikey で作成したキー（AI 分析に使う。無料で作れます）
- **モデル名**: ふつうは空欄のままで OK（`gemini-flash-latest` = 最新の Flash を使います）
- **身長・左打ち**: 体の動きの計測に使います（頭の動きの cm 換算、左右の入れ替え）

体の計測に使うモデル（約9MB）は、初めて計測するときに自動でダウンロードされます。
スロー撮影の動画はテンポが正しく測れないので、通常の速さで撮ってください。
- **取り込みフォルダ**: 長い動画を入れておくフォルダ（例: `G:\マイドライブ\ゴルフ動画`）

記録の保存先やポート番号は `pc\config.json` で変えられます（初回起動時に作られます）。

```json
{ "data_dir": "D:/golf-data", "port": 8765 }
```

## アプリの更新（ボタン1つ）

設定タブの「アプリの更新」に GitHub の読み取り専用トークンを一度入れておくと、新しい版が出たときに画面の上に
「新しい版があります」と出ます。「更新する」を押すと、GitHub から新しい版を取ってきて上書きし（`data` と `config.json` はそのまま）、
自動で起動し直して画面も読み直します。ZIP を落として上書きする必要はありません。

- トークンの作り方: GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token。
  Repository access は「Only select repositories」で golf だけ、Permissions の Contents を「Read-only」にします。
- 自動で起動し直すのは、`start.bat`（中で `launcher.py` を動かす）で起動したときだけです。
- `start.bat` 自体が変わったときは `start.bat.new` として置くので、次に自分で起動し直す前に名前を変えてください。

## ほかの人に配る

`dist/` に配布用の中身（install.bat・install.ps1・やさしい README・update.json）があります。
`python dist/build.py <フォルダ>` で、公開リポジトリ kosuke20127-droid/golf-practice-app に置く中身を作れます。
配布版は update.json で公開リポジトリから更新するので、使う人はトークンなしで「更新する」が使えます。

## 記録から学習（Claude Code）

練習タブの「コーチのメモ」で「記録から学習する（Claude）」を押すと、パソコンに入っている Claude Code（`claude` コマンド・Sonnet）に記録を読ませます。読ませるのは、計測・点数・感触・振り返りノート・テーマです。Claude はそこから「スイングの特徴・良いときの共通点・崩れるパターン・効いた練習」をまとめたメモを作ります。学習し直すたびに前のメモを見直して書き直すので、記録が増えるほどあなた向けになります。メモの要約は、Gemini の分析や振り返りノートの整理にも使われます。

- 先に Claude Code を入れて、コマンドプロンプトで一度 `claude` を起動してログインしておいてください。
- 画像は送らず、文字の記録だけを読ませます。Claude の利用枠を使います。
- コマンドの場所やモデルは、設定タブで変えられます。

## うまく動かないとき

- **更新したのに保存できない・新しい機能が動かない**: ZIP を上書きしたあとは、start.bat の黒い画面を閉じて、もう一度 start.bat を起動してください。開いたままだと古いアプリが動き続けます。
- **「姿勢を測る」で何も測れない**: start.bat の黒い画面に出る「姿勢の計測: …」を見てください。
  「mediapipe を読み込めません」と出ているときは、Python のバージョンが新しすぎて mediapipe が入っていないことが多いです。
  `winget install Python.Python.3.12` で Python 3.12 を入れ、start.bat を実行し直してください。
- **AI 分析の後に点数が付かない**: 記録を開いて「点数を付ける」を押すと、分析の文章から点数だけを付け直します（画像は送らないので軽いです）。

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `server.py` | サーバー本体（画面の配信・保存・動画処理の受付） |
| `video.py` | インパクト検出、コマ画像、クラブ軌道画像、動画の切り出し |
| `pose.py` | MediaPipe で体の動きを測る |
| `ai.py` | Gemini API でのスイング分析 |
| `static/` | スマホ向けの画面 |
| `start.bat` | Windows 用の起動ファイル |
| `data/` | 記録・画像・動画（自動で作られます） |
