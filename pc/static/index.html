スマホから使う

オンにすると、同じ Wi-Fi につないだスマホから、このパソコンのアプリを開けます（家の Wi-Fi で使ってください）。 はじめてオンにしたとき、Windows に「アクセスを許可しますか」と聞かれたら「許可」を押してください。

アプリの更新

GitHub の読み取り専用トークンを一度入れておくと、新しい版が出たときにボタン1つで更新・起動し直しできます（data の記録はそのままです）。

トークンの作り方
  1. GitHub にログインして、右上のアイコン → Settings → 左の一番下 Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
  2. Token name は「golf更新」など。Expiration は 1年（期限が切れたら作り直し）
  3. Repository access で「Only select repositories」→ golf を選ぶ
  4. Permissions → Repository permissions → Contents を「Read-only」に
  5. Generate token を押して、出てきた github_pat_ で始まる文字をここに貼って保存

記録から学習（Claude・詳しい人向け）

コーチのメモは、ふつうは Gemini で作ります。パソコンに Claude Code（claude コマンド）が入っていれば、代わりにそちらを使います（Claude の利用枠を使います）。 使うときは、コマンドプロンプトで一度 claude を起動してログインしておいてください。入っていなければ、ここは空欄のままで大丈夫です。
